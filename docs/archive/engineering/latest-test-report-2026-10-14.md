## 安全发布阻断与恢复缺口

本节保留风险、证据等级和影响边界，但不公开可直接利用的 SQL 输入、漏洞逐行定位或复现操作序列。

### P0：两项阻断未在本报告中关闭

1. **Direct SQL 校验与实际执行文本存在不一致。** 隔离合成反例已确认授权/资源检查漏检，可出现不应被放行的授权结果。真实 SQLite 驱动拒绝了相关多语句执行；**没有证明真实 PostgreSQL/MySQL 写入或数据泄露**，也没有实测这些数据库上的相应副作用。驱动偶然拒绝不能替代 Runtime 的只读和资源授权不变量。
2. **Pi 事件去重缺少主体作用域。** 隔离合成环境已观察到合法不同主体复用同一事件标识时，返回先前主体的任务投影。该结果证明存在隔离缺口，**不表示已经证明任意任务枚举或真实客户泄露**。

关闭这些阻断需要对完整受支持 SQL 的效果与资源授权、校验对象和执行对象绑定，以及跨主体去重返回的授权边界给出修复与回归证据。测试总数不能代替该验收。

### 其他已记录缺口

- **P1 授权撤销竞争窗口：** 合成反例记录了认证与授权管理事务之间的撤销时序缺口；新 HTTP 请求使用已撤销凭证会被拒绝，不应泛化为所有撤销失效。
- **P1 会话注销：** 原评估观察到注销清除客户端 Cookie，但旧会话仍可认证直至到期；未提供后续服务端会话撤销验收。
- **P1 报告发布恢复：** 合成故障反例发现发布结果不确定时重新生成内容会破坏原发布幂等；不是完整真实远端 HTTP 丢响应测试。
- **P1 任务终态恢复与取消：** 合成反例发现部分远端失败/取消终态没有正确收敛，以及 prepare 取消语义与其他阶段不一致。
- **P2 [INFERENCE] 租约与审批到期：** 状态可能滞留的风险由源码推导；原评估没有完整运行复现相应时间窗口，不能写成已发生事故。
