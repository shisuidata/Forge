## SQL 生成的三类错误

LLM 生成 SQL 的错误不是一个笼统的"不准"，而是三个截然不同的问题。

<CardGrid>
  <Card title="生成错误 — 已解决" icon="approve-check">
    推理对了，SQL 写错了。`INNER JOIN` 替代 `LEFT JOIN`、`NOT IN` 遇 NULL 静默返错。

    **Forge 方案**：DSL 约束 + Structured Output，token 级别约束，物理上不可能出错。
  </Card>
  <Card title="业务逻辑错误 — 已解决" icon="approve-check">
    指标定义歧义。"复购率"的分母是谁？"销售额"含不含退款？

    **Forge 方案**：Registry 语义层，指标定义一次，全组织统一口径。
  </Card>
  <Card title="算法逻辑错误 — 超出边界" icon="warning">
    不知该用什么算法。日期序列填充、递归 CTE。

    **Forge 态度**：诚实标注，不假装能做。超出 DSL 表达能力的查询明确告知。
  </Card>
</CardGrid>

## 工作原理

```
自然语言 → Registry(语义+结构) → LLM(Structured Output) → Forge JSON → 确定性编译器 → SQL → 审核执行
```

**关键区别**：传统方案让 LLM 直接输出 SQL（概率生成，不可预测的错误）。Forge 让 LLM 输出结构化的 JSON，由确定性编译器翻译为 SQL。编译器的行为是可测试、可调试、可升级的——和 prompt 蝴蝶效应完全不同。

## 四个核心信念

<CardGrid stagger>
  <Card title="01 · 约束是自由的前提" icon="seti:lock">
    收窄输出空间，让整类错误在物理上不可能发生。JSON Schema 在 token 级别约束——不是"建议"LLM，而是让它**不可能不这样做**。
  </Card>
  <Card title="02 · 意图与执行分离" icon="seti:pipeline">
    LLM 负责理解意图（生成 JSON），编译器负责正确执行（翻译 SQL）。编译器修了一个 bug，所有 LLM 都受益。
  </Card>
  <Card title="03 · Registry 是组织数据资产" icon="seti:db">
    结构层 `forge sync` 自动生成，语义层通过对话持续积累。"复购率"的定义只需说一次，从此全组织统一。
  </Card>
  <Card title="04 · 编译器修复优于 Prompt 修复" icon="seti:config">
    改 prompt 是蝴蝶效应。改编译器是确定性的——14 个 `_coerce` 修复有单元测试保护，永远不会回退。
  </Card>
</CardGrid>

## 五分钟上手

<Tabs>
  <TabItem label="pip 安装">
    ```bash
    git clone https://github.com/shisuidata/Forge
    cd Forge && pip install -e .
    cp .env.example .env   # 填入 LLM_API_KEY + EMBED_API_KEY
    bash scripts/demo-setup.sh
    uvicorn main:app --host 0.0.0.0 --port 8000
    ```
  </TabItem>
  <TabItem label="Docker（推荐）">
    ```bash
    git clone https://github.com/shisuidata/Forge
    cd Forge
    cp .env.example .env   # 填入 LLM_API_KEY + EMBED_API_KEY
    docker compose up
    # 访问 http://localhost:8000
    ```
  </TabItem>
  <TabItem label="生产 Smoke">
    ```bash
    cp .env.production.example .env.production
    docker compose -f docker-compose.prod.yml --env-file .env.production up -d --build
    bash scripts/production-smoke.sh
    ```
  </TabItem>
  <TabItem label="接入自己的数据库">
    ```bash
    # 修改 .env 中的 DATABASE_URL
    forge sync --db postgresql://user:pass@host/db
    uvicorn main:app --host 0.0.0.0 --port 8000
    ```
  </TabItem>
</Tabs>
